## 👋 Ciao, siamo Mynd

Siamo un team di oltre **20 Mynders**, tra creativi, designer e sviluppatori, con **più di 18 anni di esperienza**. Dalla nostra sede di Vimercate progettiamo esperienze digitali che uniscono creatività, strategia e tecnologia.

In questa organizzazione GitHub trovi il lato più tecnico del nostro lavoro: siti, piattaforme, design system e strumenti interni.

## 🔁 Il nostro metodo: MyndSET

Un processo ciclico ispirato al **Design Thinking**, che ripetiamo a ogni iterazione:

```
  Scoprire  ──▶  Esplorare  ──▶  Testare
     ▲                              │
     └──────────────────────────────┘
```

- **Scoprire**: interviste agli utenti, ricerca etnografica, survey, stakeholder mapping
- **Esplorare**: brainstorming, storyboard, co-design, sketching
- **Testare**: user test, A/B test, tree test, valutazione euristica
